# Contributing

Thanks for considering a contribution.

1. Open an issue describing the problem or proposed improvement.
2. Fork the repository and create a focused branch.
3. Make a small, clearly scoped change.
4. Test the app locally with `streamlit run app.py`.
5. Submit a pull request explaining what changed and how you tested it.

Do not add unverified legal or regulatory requirements. Cite authoritative sources and identify the product and destination market when proposing checklist changes.
